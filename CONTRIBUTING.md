# Contributing to BNO Travel Tracker

Thank you for your interest in contributing! This project aims to help BNO visa holders track their travel history for settlement applications.

## How to Contribute

1.  **Report Bugs**: Open an issue describing the bug and how to reproduce it.
2.  **Suggest Features**: Open an issue with your suggestion and why it would be helpful.
3.  **Submit Pull Requests**:
    *   Fork the repository.
    *   Create a new branch for your feature or bug fix.
    *   Submit a PR with a clear description of your changes.

## Development

This is a vanilla web project (HTML/CSS/JS). No build step is required.
1.  Clone the repository.
2.  Open `index.html` in your browser to test.

## Translation

Improvements to the Cantonese/English translations are always welcome!
